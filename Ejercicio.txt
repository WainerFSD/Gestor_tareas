EJERCICIO: GESTOR DE TAREAS CON POO

Crea un programa en Python utilizando una clase llamada GestorTareas.

Debes guardar las tareas en un archivo llamado:

tareas.json


ESTRUCTURA DE UNA TAREA:

{
    "id": 1,
    "nombre": "Estudiar Python",
    "completada": false,
    "fecha": "20/08/2026 10:30"
}


EL PROGRAMA DEBE TENER UN MENÚ:

1. Agregar tarea
2. Ver tareas
3. Marcar tarea como completada
4. Salir


FUNCIONALIDADES:

1. AGREGAR TAREA

- Pedir al usuario el nombre de la tarea.
- Validar que el nombre no esté vacío.
- Asignar un ID automáticamente.
- Obtener la fecha y hora actual usando datetime.
- La tarea debe comenzar con:

    "completada": False

- Agregar la tarea a la lista.
- Guardar las tareas en tareas.json usando json.dump().


2. VER TAREAS

- Cargar las tareas desde tareas.json usando json.load().
- Mostrar todas las tareas.

Ejemplo:

ID: 1
Tarea: Estudiar Python
Estado: Pendiente
Fecha: 20/08/2026 10:30

ID: 2
Tarea: Hacer ejercicio
Estado: Completada
Fecha: 21/08/2026 15:00


3. MARCAR TAREA COMO COMPLETADA

- Pedir al usuario el ID de la tarea.
- Buscar la tarea.
- Si existe:

    tarea["completada"] = True

- Guardar nuevamente las tareas en el archivo JSON.

- Si no existe, mostrar:

    La tarea no existe.


4. MANEJO DE EXCEPCIONES

Debes manejar:

- ValueError:
  Si el usuario ingresa algo que no sea un número cuando se pide un ID.

- FileNotFoundError:
  Si tareas.json todavía no existe.

  En ese caso puedes devolver una lista vacía:

    []

- Exception:
  Para manejar errores inesperados.
